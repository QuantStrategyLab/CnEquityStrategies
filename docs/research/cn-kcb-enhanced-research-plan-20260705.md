# 科创板增强策略研究计划（2026-07-05）

**状态：** research_backtest_only
**目标：** 先把科创板从“挑最强”改成“板块增强”，再看是否有资格进入更高一级评审。

---

## 1. 方案定位

科创板不建议继续走很窄的冠军筛选路线，原因和创业板类似，但更明显：

- 波动更大；
- 流动性更敏感；
- 退市和异常波动风险更高；
- 单票或小样本冠军容易被风格行情带着跑。

所以科创板更合理的形态是：

**“科创板基准 + 多因子增强 + 更强风控”**

优先顺序建议：
1. 科创50 / 科创综合作为基准
2. 质量 + 动量 + 流动性 + 风险惩罚
3. 明确单票 cap、行业 cap、trend filter
4. 样本外先打当前 live 主轨，再谈晋级

---

## 2. 研究目标

这个版本先只验证三件事：

1. 科创板增强版是不是比现有创业板 tactical 更合理；
2. 科创板增强版能不能在同周期里不明显输给行业 ETF 主轨；
3. 如果还不行，是不是说明科创板这条线必须走更重的指数增强，而不是当前这种轻量 tactical。

---

## 3. 推荐骨架

### 3.1 Universe

- 上交所科创板股票
- 排除 ST / *ST
- 排除上市时间太短
- 以代码前缀 `688` / `689` 做研究级过滤

### 3.2 Signals

建议先保留四类：

- **Growth**：营收/利润同比、增速变化
- **Quality**：ROE、利润稳定性、现金流质量
- **Momentum**：12M-1M 动量、60/120 日趋势
- **Liquidity / Risk**：adv20、波动率、短期过热惩罚、拥挤度惩罚

### 3.3 Portfolio

- 月频调仓
- top 15–25
- 单票 cap
- 组合 gross cap
- benchmark trend filter
- 风险失效时退回 `510300` / `159915` / 现金

---

## 4. 这版先不做的事

- 不做 runtime registration
- 不做 live candidate
- 不做复杂的组合 orchestration
- 不做深度 PIT 保障

先把研究骨架补齐，等证据出来再决定是否加重风控或重做。

---

## 5. 后续验证门槛

如果这版连下面这些都做不到，就不要继续往 live 想：

- 2021–2026 全样本不明显差于现有主轨；
- 2024–2026 样本外不塌；
- 2021–2022 熊市不出现很难看的尾部；
- 流动性和单票 cap 加上后仍然能跑。
